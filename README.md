# LO-CARB Website Revamp 2027 — Design prototype

High-fidelity, interactive prototype of the new **locarb.green** (16 pages, TH/EN), built from the
*PRD LO-CARB Website Revamp*, the LO-CARB CI book and the TH/EN Content Template.

> This is a **design prototype**, not the production site. Use it as the visual and UX reference
> when building the real site (PRD N7: WordPress or rebuild, decided by the tech team).

## What's inside

| Folder | Contents |
|---|---|
| `design/` | 16 page files (`*.dc.html`) and `canvas.json` (page layout on the design canvas) |
| `assets/` | Brand fonts, images, page-loader animation, shared stylesheet `site.css`, `asset-map.json` |
| `tools/` | Python scripts that generate the inner pages, the Thai version, CI colours and button labels |

### Pages
Home · About (Story, Certificates, Board) · Solutions (IFRS, CarbonCal + Carbon Camp, ISSB training,
Carbon Scout, Reporting & consulting) · Blog (hub, Portfolio, Knowledge base, News & events,
client-story template, article template) · Contact Us.

### Features shown in the prototype
- TH/EN switch on every page (remembered between pages), text-size control A− A A+
- Mega-menu navigation, site search overlay (pages + articles, TH/EN)
- Cookie notice (Accept all / Reject non-essential, re-open from footer)
- Logo loading animation, hero entrance animation, button hover effects
- Contact form with topic/solution routing (contact@ vs hr@), PDPA consent, success message
- SEO structure: one H1, keyword H2s, H3 links for solutions and posts, `<time>` dates, alt text


## Deploy (Vercel) — use the `site/` folder

`design/*.dc.html` only run inside the Claude design canvas (they need its runtime and `/_blob/` asset URLs).
On a normal host they stop at the logo animation. **Deploy `site/` instead**: plain HTML, CSS and JS that
render the same pages (TH/EN switch, search, cookie notice, logo intro once per visit, forms, hero video).

Vercel: import the repo, Framework Preset **Other**, no build command. The root `vercel.json` sets `site` as Output Directory. Keep Vercel Root Directory at the repository root (blank), Framework Preset Other, and no build command. Old /design/*.dc.html URLs redirect to the new HTML pages.

To rebuild `site/` after design changes: `python3 tools/export.py` (paths at the top of the script).
`site/assets/morphdom.js` is morphdom 2.7.4 (MIT).

## How the files work
The `*.dc.html` files run inside the Claude design canvas (they load `./support.js` and assets via
`/_blob/...` URLs). To use the assets outside the canvas, map each `/_blob/<id>` to its file with
`assets/asset-map.json`.

## Rebuilding (optional)
`tools/Main.en.html` is the English master of the Home page. Inner pages are generated by
`tools/gen.py`, then post-processed:

```
python3 gen.py                      # generate inner pages from the master
python3 wrapbtn.py   <pages>        # wrap button labels (hover effect)
python3 bilingual.py <all pages>    # add the Thai version + search, cookie, loader logic
python3 recolor.py   <pages>        # apply CI colours (#0EA552, #000000, #F3F0DF)
```
Thai copy lives in `tools/TH.json` (EN → TH). Paths inside the scripts point to the original
working folders; update them before running.
